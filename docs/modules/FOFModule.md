# FOFModule FOF分析模块

> **最后更新**: 2026-01-21  
> **文件位置**: `src/components/modules/FOFModule.tsx`  
> **API 端点**: `/api/fof`  
> **对应页面**: `/fof`

---

## 📋 功能概述

FOF (Fund of Funds) 产品分析模块，展示 FOF 组合的底层持仓、收益归因和业绩分析。

---

## 📊 数据展示

### 持仓分析
| 指标 | 说明 |
|------|------|
| 持仓基金列表 | FOF底层持有的子基金 |
| 持仓权重 | 各子基金的配置比例 |
| 持仓市值 | 各子基金的当前市值 |

### 收益归因
| 指标 | 说明 |
|------|------|
| 子基金贡献 | 各子基金对组合收益的贡献 |
| 策略贡献 | 各策略类型的收益贡献 |
| 时间归因 | 不同时间段的收益来源 |

---

## 🔌 数据源

### 主数据源: SQLite + 飞书
- **数据库表**: `fof_holdings`, `funds`
- **同步方式**: 飞书多维表格
